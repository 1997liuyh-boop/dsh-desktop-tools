# dsh-desktop-tools 后续迭代设计

> 写于 0.6.0 开发期间（2026-11-16）。0.5.0 补了稳定性（诊断页、主流程测试），0.6.0 补了体验（自定义划词动作、截图直接提问、钉图管理）。本文列出之后的候选项，供排期参考，不代表承诺。

每一项都包括：**动机**、**方案要点**、**涉及文件**、**风险**、**验收标准**。优先级：P0 必须尽快做，P1 下个版本，P2 视情况。

---

## 一、架构问题（开发 0.5 / 0.6 时发现）

### 1. 保存设置不再整体重启辅助进程（P0）
- **动机**：现在设置页每保存一次，`DesktopToolsController.update()` 都会调用 `reconcile()`：停掉全部功能、销毁辅助进程、再整体重建。只改一个录屏格式，也会关掉正在显示的划词结果窗、截图结果窗和悬浮球对话。0.6 用持久化保住了钉图，但其他窗口仍会丢失。
- **方案要点**：
  - 比较新旧配置，只重启真正变化的功能。各功能已经是独立扩展（`dsh-capture`、`dsh-selection-toolbar`、`dsh-floating-ball`），可以分别 deactivate / activate。
  - 只改了参数的功能（快捷键、格式、模型），改为向辅助进程发送 `config-changed`，由各插件就地重读配置：快捷键重新注册，划词控制器替换 `config`。
  - 只有启用状态变化、或辅助进程异常时，才整体重建。
- **涉及文件**：`native-extension-runtime/desktop-tools-service.ts`（reconcile）、`helper.ts`（新命令）、`desktop-capture-plugin.ts`、`selection-toolbar-controller.ts`、`desktop-floating-plugin.ts`。
- **风险**：配置读取散落在多个模块，而且大多只在 activate 时读一次（截图插件的 `config` 是快照）。需要逐个改成可刷新。
- **验收**：改录屏格式并保存后，已打开的划词结果窗、截图结果窗和悬浮球对话都不关闭；改快捷键后立即生效；`desktop-tools-service.test.ts` 增加「只重启变化的功能」用例。

### 2. 辅助进程语言跟随 DSH（P1）
- **动机**：辅助进程的界面语言在启动时按系统语言固定（`helper.ts` 中 `locale`），用户在 DSH 里切换语言后，托盘、悬浮球菜单和截图工具栏不会跟着变。
- **方案要点**：Host 把 DSH 当前语言随 `dsh-native-ready` 之后的首个命令下发，语言变化时推送 `locale-changed`；`environment.locale()` 改为读取可变值，菜单通过 `environment.changed()` 重建。
- **涉及文件**：`helper.ts`、`desktop-feature-host.ts`、`native-extension-runtime/index.ts`。
- **验收**：在 DSH 中把语言从中文切到英文，托盘菜单和新打开的截图工具栏随之变为英文。

### 3. 钉图会被之后的截图拍进去（P2）
- **动机**：钉图窗口没有开启 `setContentProtection`，再次截图时会出现在画面里。有人希望拍进去（拼对比图），有人不希望。
- **方案要点**：新增设置「截图时隐藏钉图」，默认关闭。开启后，截图开始前临时隐藏全部钉图，结束后恢复。不用 content protection，因为它会让钉图在录屏和共享屏幕时也变成黑块。
- **涉及文件**：`desktop-capture.ts`（open / close）、配置与设置页。
- **验收**：开启后截图，画面里没有钉图；截图结束后钉图恢复原状。

### 4. 拆分大文件（P1）
- **动机**：`locale.ts`（约 2200 行）、`desktop-capture.ts`（约 1000 行）、`floating-window.ts`（约 840 行）、`capture-ui/main.ts`（约 800 行）都在继续变大，评审和定位都变慢了。
- **方案要点**：
  - `locale.ts` 按功能拆成 `locale/selection.ts`、`locale/capture.ts` 等，再由 `locale/index.ts` 合并；
  - `desktop-capture.ts` 拆成采集（overlay / 录屏 / 长截图）、结果窗（OCR、翻译、图谱、提问）和钉图三个类；
  - 只做结构调整，不改变行为。
- **验收**：拆分前后 `npm test` 与构建产物的行为一致，实机走查截图、录屏、钉图、提问都正常。

## 二、功能候选

### 5. 截图 / 录屏历史（P1）
- **动机**：截图结果窗、OCR 和翻译的结果一关就找不回来。
- **方案要点**：
  - 在 `profile/desktop-tools/history/` 保存最近 100 条记录，每条包括缩略图、原图路径、类型和识别文字；录屏只记文件路径，不复制视频；
  - 设置页新增「历史」标签，也可以从悬浮球菜单打开：可以复制、再次提问、钉到桌面、删除；
  - 提供「不保存历史」开关，以及一键清空。
- **涉及文件**：新建 `capture-history-store.ts`（参照 `capture-pin-store.ts`）、`desktop-capture.ts`、设置页。
- **风险**：截图可能包含隐私，默认需要明确告知用户，并提供清空入口。
- **验收**：截图、OCR 后关闭窗口，在历史里能找到并重新复制；关闭开关后不再记录。

### 6. 录屏语音转写（P2）
- **动机**：现在「录屏转知识图谱」只用关键帧的 OCR，会议和讲解类录屏的主要信息都在语音里。
- **方案要点**：录制时单独保存音轨，结束后交给转写服务。优先复用 DSH 已有的语音能力（profile 中的 `@deepseek-ai/dsh-experimental-voice-input-bundle`），不可用时提示安装；转写结果按时间戳与关键帧合并后生成纪要和字幕（SRT）。
- **风险**：转写服务不确定，长音频的耗时和费用也不确定。需要先确认 DSH 语音插件是否提供可调用的工具接口。
- **验收**：录 3 分钟带讲解的屏幕，得到带时间戳的纪要和 SRT。

### 7. 截图多轮对话升级（P2）
- **动机**：0.6 的追问是每轮新建会话，再附上最近三轮问答，上下文有限，也看不到 DSH 里的会话。
- **方案要点**：首轮之后，在同一个会话里继续用 `session/prompt`，需要 `SelectionSessionTask` 支持复用 sessionId；结果窗提供「在 DSH 中继续」，直接打开这个会话，而不只是显示主窗口。
- **涉及文件**：`selection-session.ts`、`desktop-capture.ts`、`capture-ui/result.ts`。
- **验收**：连续追问五轮，回答能引用第一轮的内容；点击「在 DSH 中继续」后打开的正是这个会话。

### 8. 自定义划词动作增强（P2）
- **方案要点**：
  - 每个动作可以单独选模型，没设置时沿用划词模型；
  - 可以给动作绑定全局快捷键，选中文字后直接运行；
  - 提供导入 / 导出（JSON），方便分享动作；
  - 提供几个内置模板：润色、总结、代码解释、改写为正式语气。
- **涉及文件**：`desktop-tools-config.ts`（`customActions` 增加 `model?`、`shortcut?` 字段）、`SelectionActionsEditor.tsx`、`selection-assistant.ts`。
- **验收**：给「润色」绑定 `Ctrl+Alt+P`，在任意应用里选中文字后按下，弹出结果窗。

### 9. Linux 补齐（P2）
- **方案要点**：系统声音改用 PipeWire / PulseAudio 的 monitor 源；长截图自动滚动在 X11 下用 xdotool、Wayland 下用 ydotool 兜底；系统分享改为「打开所在文件夹」。
- **风险**：Wayland 的权限限制很多，需要实机矩阵测试。
- **验收**：Ubuntu 24.04（X11 / Wayland 各一）上录到系统声音，长截图能自动滚动。

### 10. 跟进 DSH 正式版（P1）
- **方案要点**：DSH 0.2.x 发布正式版后，把 `package.json` 里的 `compatibility.dshReleases` 从 experimental 改为 stable，并补一份版本对照表；诊断页增加「DSH 版本在兼容范围内」检查。
- **验收**：在正式版 DSH 上安装后诊断全部正常，README 写明支持的版本。

### 11. 性能（P2）
- **方案要点**：长截图拼接（`stitch.ts`）放到 Worker 中执行；辅助进程按需加载功能，截图和录屏关闭时不加载对应模块；记录冷启动耗时和常驻内存，作为后续优化的基线。
- **验收**：30000 像素高的长截图，拼接过程中工具栏不卡顿；只启用划词时，辅助进程内存比现在下降。

## 三、建议排期

| 版本 | 内容 |
|---|---|
| 0.7 | 1 保存设置不再整体重启、2 语言跟随 DSH、5 截图/录屏历史、10 跟进 DSH 正式版 |
| 0.8 | 4 拆分大文件、7 多轮对话、8 自定义动作增强、3 截图时隐藏钉图 |
| 之后 | 6 语音转写、9 Linux 补齐、11 性能 |

0.7 优先做第 1 项：它直接影响日常使用（保存一次设置就丢窗口），后面几项功能也要依赖「配置可热更新」这个基础。
