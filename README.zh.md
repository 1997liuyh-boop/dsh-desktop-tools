# dsh-desktop-tools

[English](README.md) | 中文

`dsh-desktop-tools` 将划词工具栏、悬浮球、截图、长截图和录屏合并为一个 DSH Desktop 插件。

## 安装

使用满足 `>=0.2.2-rc.1 <0.3.0-0` 的 DSH Desktop，在插件管理器中添加：

```text
https://github.com/1997liuyh-boop/dsh-desktop-tools.git
```

选择精确标签 `0.8.0`。插件已经包含辅助进程、预加载脚本、原生功能模块、静态资源和设置页，不需要再安装 `dsh-desktop-runtime`、`dsh-selection-toolbar`、`dsh-floating-ball` 或 `dsh-capture`。

安装不依赖 Electron 的 `path.txt`，也不使用 `koffi` 安装脚本。辅助进程会加载对应平台的 Koffi 预编译包。

## 前置条件：独立 Electron

插件的各项功能运行在单独的 Electron 辅助进程中，插件本身不会下载 Electron。启动哪个可执行文件取决于 DSH Desktop 的安装方式：

- **安装版 DSH Desktop**（安装包安装，可执行文件旁有 `resources/app.asar`，例如 `DeepSeek Harness.exe`）：这个程序只会启动 DSH 自身，因此**需要另备一个独立 Electron**。辅助进程按以下顺序使用找到的第一个：
  1. 插件设置中的 `electronExecutable`；
  2. 环境变量 `DSH_DESKTOP_TOOLS_ELECTRON`；
  3. `$DSH_HOME/electron/`（默认 `~/.dsh/electron/`）：Windows 为 `electron.exe`，macOS 为 `Electron.app/Contents/MacOS/Electron`，Linux 为 `electron`。把 Electron 官方发布的压缩包解压到该目录即是这个结构。

  都找不到时，启用功能会失败并列出已尝试的路径，设置页会显示这条错误。
- **由裸 Electron 启动的 DSH Desktop**（开发模式）：辅助进程直接复用该 Electron，无需额外准备。

请使用与 DSH Desktop 相同大版本的 Electron，其他版本未经测试。

## 前置插件：dsh-vision-router

截图与长截图的「提取文字」「翻译」「知识图谱」，以及「录屏转知识图谱」，都通过 [`dsh-vision-router`](https://github.com/ysr666/dsh-vision-router)（`>=3.2.0`）的 OCR 工具识别文字，需要先安装并启用它，并保持其设置中的「工具」开关打开。其余功能（标注、钉图、保存、转发、录屏、长截图拼接）不依赖它。

DSH 插件管理器不支持插件之间的自动联动安装，可以用以下任一方式安装：

- 在「设置 → 桌面工具 → 截图」的前置插件卡片中点击「一键安装 dsh-vision-router」（已安装但停用时为「启用」），安装后按提示重启 DSH；
- 截图工具栏中点击这三个功能时，如果尚未安装，结果窗口会显示同样的一键安装按钮；
- 或在终端执行 `dsh plugin add dsh-vision-router`。

`package.json` 以可选 `peerDependencies` 声明了该依赖，插件市场的检查会在版本不满足时给出提示。默认 OCR 引擎为 `auto`：本地 Tesseract 优先，不可用时回退到 vision-router 配置的视觉模型（图片会发送给该模型服务）；如需纯本地，请在 vision-router 设置中把 OCR 默认引擎改为仅 Tesseract。

## 截图、长截图与录屏

按下快捷键（系统级，DSH 在后台也能唤起）后，屏幕顶部出现工具栏，可在「截图 / 录屏 / 长截图」三种模式间切换。

截图：框选区域后可使用

- 形状（矩形 / 椭圆 / 直线，按住 Shift 约束为正方形、圆或 45°）、画笔、箭头、文本（文本 / 自动递增的序号）、马赛克（涂抹，可调强度），以及颜色、粗细、字号；
- 钉在桌面（置顶浮窗，可拖动、滚轮缩放，双击或 Esc 关闭，右键复制 / 保存 / 原始大小 / 对这张图提问）。钉图保存在 profile 的 `desktop-tools/pins/` 中（最多 30 张），保存设置或重启后自动恢复，关闭钉图时一并删除；托盘菜单「钉图（N）」和悬浮球右键菜单「钉图管理…」可以统一显示、隐藏、关闭，管理窗里能逐张定位、复制、保存、提问；还可以在设置中给「显示 / 隐藏全部钉图」设置全局快捷键；
- 提问：在独立窗口里直接对截图提问，回答流式显示，可以连续追问（会带上最近三轮问答），提供「这是什么 / 总结要点 / 找出问题」快捷问题。图片直接发给当前模型；模型不支持图片时，可以一键改用 dsh-vision-router 识别出的文字提问。长截图直接按识别文字回答；
- 长截图（以当前选区为范围开始滚动截取）；
- 知识图谱转换、翻译、提取文字（需要 dsh-vision-router）：在独立结果窗口中显示，翻译与知识图谱会在「截图录屏」工作区新建 DSH 会话，知识图谱以 Mermaid 关系图加节点、关系清单呈现，可保存为 Markdown 或导出 PNG；
- 撤回（Ctrl/Cmd + Z）、转发（发送到新的 DSH 对话，可附言；或调用系统分享面板）、保存到本地（Ctrl/Cmd + S）、取消（Esc）、完成（复制到剪贴板，Enter）。

录屏：

- 录制范围：框选区域、选择应用窗口或全屏；
- 格式 MP4 / GIF / WebM（Chromium 不支持 MP4 编码时自动改用 WebM），清晰度 标清 720p / 高清 1080p / 原画；
- 系统声音、麦克风（两路同时开启时混为一条音轨），GIF 不含声音；
- 录屏转知识图谱：录制中自动抽取画面明显变化的关键帧（最多 12 张），结束后识别文字并生成知识图谱；不转写语音；
- 开始录制后变为顶部控制条，可暂停 / 继续（空格）、停止并保存（Enter）、放弃（Esc）。MP4 / WebM 最长 15 分钟、500 MB，GIF 最长 3 分钟。

长截图：框选需要滚动的区域，点「开始」后在框内用鼠标滚轮向下滚动，插件按行比对自动拼接并排除固定的顶栏和底栏；也可点「自动滚动」。完成后可复制、保存、钉图、提取文字、翻译、生成知识图谱或转发。最大高度 30000 像素。

平台限制：

| 功能 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 系统声音 | 支持 | macOS 13+，不可用时自动改为只录画面 | 不支持 |
| 长截图自动滚动 | 支持 | 需要辅助功能权限 | 不支持（可手动滚动） |
| 系统分享 | 资源管理器「共享」面板 | 系统共享菜单 | 不支持 |

## 替换旧插件

如果 profile 中已经安装了旧插件，请先移除 `dsh-selection-toolbar`、`dsh-floating-ball`、`dsh-capture` 和 `dsh-desktop-runtime`，再安装 `dsh-desktop-tools@0.8.0` 并重启 Host。新插件将配置保存在 `desktop-tools.json`，不会导入旧插件各自的配置文件。默认启用划词工具栏和悬浮球，关闭截图和录屏。

## 设置

DSH 设置中会增加一个“桌面工具”入口，下设六个子菜单：

- 划词工具栏：启用状态、目标语言、模型、兼容复制，以及工具栏按钮：可以开关、调整顺序，并添加最多 10 个自定义动作（名称 + 提示词，`{text}` 替换为选中文字，`{language}` 替换为目标语言）。自定义动作和翻译、解释一样在结果窗中流式输出。
- 悬浮球：启用状态、头像、对话和后台模型、权限预设、坐标模式及系统权限。
- 用量与余额：DeepSeek API / DSH 账户实际余额、本机 token 用量、按模型配置的人民币单价，以及每日估算预算。
- 截图：启用状态、截图快捷键（默认 `Ctrl/Cmd + Shift + S`）、长截图快捷键（默认不设置）以及 dsh-vision-router 状态与一键安装。
- 录屏：启用状态、录屏快捷键（默认 `Ctrl/Cmd + Shift + R`），以及默认格式、清晰度、系统声音、麦克风和是否生成知识图谱。
- 诊断：逐项检查配置文件、辅助进程使用的 Electron（路径以及与 DSH 的版本是否一致）、Koffi 原生模块、辅助进程与各项功能、全局快捷键注册、dsh-vision-router 以及 macOS 系统权限。每项显示「正常 / 需要注意 / 异常 / 不适用」，可以直接在该项上重启辅助进程、安装或启用 dsh-vision-router、打开系统权限设置。「复制诊断报告」会复制一份纯文本报告，可附在问题反馈中。

快捷键为系统级全局快捷键，被其他程序占用时不会注册（「诊断」页会列出），请换一个组合。首次安装默认启用划词工具栏和悬浮球，关闭截图和录屏。配置保存在 profile 的 `desktop-tools.json` 中，每次保存都会分别报告持久化结果和辅助进程的实际应用状态。

保存设置时只启停开关发生变化的功能，其余功能就地读取新配置（快捷键重新注册、划词按钮与语言、录屏默认值等立即生效），已打开的结果窗、悬浮球对话和钉图都不会被关闭。例如关闭截图只会关闭截图相关的窗口。诊断页的「重启辅助进程」仍会整体重建。

桌面工具的界面语言跟随 DSH 的语言设置：在 DSH 中切换语言后，托盘菜单、悬浮球右键菜单、划词工具栏和之后打开的窗口立即使用新语言；悬浮球面板在下次启动时更新。

截图历史（默认开启）：复制、保存、钉图、转发的截图，提取文字 / 翻译 / 知识图谱 / 提问的结果，以及保存的录屏路径，会记录在 profile 的 `desktop-tools/history/` 中（最多 100 条）。从托盘「截图历史…」、悬浮球右键菜单或设置页打开历史窗，可以复制图片或文字、再次提问、钉到桌面、打开所在文件夹、删除或全部清空；在「设置 → 桌面工具 → 截图」中可以关闭记录或清空历史，清空不会删除你自己保存的文件。

## 悬浮球交互与记账

点击悬浮球打开对话并聚焦输入框，按住拖动调整位置。松开时在设定距离内吸附边缘（默认 24 个逻辑像素）：左右收为细条，上下贴到工作区边缘并保持球体可见。悬停或点击细条可恢复悬浮球。设置页可以关闭吸附、气泡与提醒。

任务气泡显示执行中、等待提问 / 授权处理、已结束及失败状态，点击气泡或完成通知进入对应会话。完成提醒根据实时轮次触发，读取聊天历史和修改会话标题不会重复提醒；对话面板展开时气泡隐藏。

「用量与余额」分别展示实际余额与本机估算。余额优先读取 DSH 的 `DEEPSEEK_API_KEY` 凭据，失败或缺失时尝试可选的 DSH 账户服务，密钥始终留在 Host 进程中；余额缓存一分钟。输入、缓存输入、缓存创建、输出 token 分开计数，推理 token 已包含在输出中。请按服务商 / 模型配置单价，未配置部分明确标记为未计价；修改单价只影响后续消息。每日预算为 0 时不提醒，提醒按本地日期的人民币估算触发，不会强制限额。

本机账本位于 `profile/desktop-tools/usage.json`，仅记录开启期间收到的新事件，按日期保留总计，并通过会话事件序号防止重复记账；不导入历史会话，也不替代官方账单。任务状态约每 1.5 秒刷新一次，系统通知是否显示取决于平台支持和系统通知设置。气泡、提醒和用量记录默认开启，旧配置自动补齐默认值。

以上功能参考了 [DeepSeek Balance Whale Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的交互与记账思路。

## 构建

使用 Node 24.9 或更新版本：

```sh
npm install --ignore-scripts
npm test
npm run build
```

构建会生成 Host、辅助进程、预加载、Remote 描述、Client 设置包和基于 TwCSS 的资源。在 macOS 上构建时会编译 macOS 原生模块；Windows 和 Linux 会保持这些 Darwin 专用模块不可用。
